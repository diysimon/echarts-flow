开发者文档

echarts-flow 是基于 ECharts 6 可注册自定义系列的流程图与泳道图扩展。你可以只用它渲染，也可以用内置的 FlowEditor 获得完整交互编辑。

安装

通过 npm 安装，ECharts 6 作为对等依赖。

npm install echarts-flow echarts

快速上手：只读渲染

注册扩展后，用 buildFlowOption 把图数据转成 ECharts option。自动布局会补全没有坐标的节点。

import * as echarts from 'echarts/core';
import { CustomChart } from 'echarts/charts';
import { CanvasRenderer } from 'echarts/renderers';
import { flowExtension, buildFlowOption } from 'echarts-flow';

echarts.use([CustomChart, CanvasRenderer, flowExtension]);

const chart = echarts.init(document.getElementById('chart'));
chart.setOption(buildFlowOption({
  nodes: [
    { id: 'a', label: '开始', shape: 'start' },
    { id: 'b', label: '处理', shape: 'process' },
  ],
  edges: [{ id: 'e1', source: 'a', target: 'b' }],
}));

交互编辑器

需要拖拽、连线、撤销重做时，用 FlowEditor 包住一个 ECharts 实例。每项编辑能力都能通过 edit 选项开关。

import { FlowEditor } from 'echarts-flow';

const editor = new FlowEditor(chart, {
  graph,
  editable: true,
  onChange: (next) => console.log(next),
});

核心概念

  • 自定义系列：网格、泳道、连线、节点和编辑层各是一个 custom series，通过 echarts.use(flowExtension) 注册。
  • itemPayload：每个系列的数据通过 itemPayload 传入 renderItem，渲染是纯函数。
  • 主题：8 套内置主题，createFlowTheme 做深度覆盖，支持渐变色。
  • 编辑能力：所有交互经 edit 选项与 setEditOptions() 控制；API 调用不受开关限制。
