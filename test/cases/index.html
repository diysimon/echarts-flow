echarts-flow 用例

每个页面覆盖一类使用场景，用于手动验证和回归检查。运行 npm run dev 后访问本页。

  • 01 只读展示

    不用编辑器，buildFlowOption 直接渲染；自动布局、居中、点击事件拿到命中信息。

  • 02 节点形状与状态

    5 种形状 × 5 种状态矩阵，手动坐标，长文本自动加宽与截断。

  • 03 布局方向与回边

    同一份带循环的数据分别用 TB 和 LR 布局，检查回边绕行。

  • 04 从空白画布编辑

    添加节点、拖线、框选（Shift+拖）、复制粘贴、方向键微调、对齐线、拖连线端点改接、撤销重做。

  • 05 运行状态监控

    只读模式下按脚本推进 CI/CD 流水线状态，含并行、失败和重试。

  • 06 JSON 导入导出

    画布与 JSON 双向同步，导入校验，可选去掉坐标重新布局。

  • 07 大图性能

    50 到 1000 个节点，记录布局与渲染耗时，检查交互流畅度。

  • 08 多实例与 SVG 渲染

    Canvas 和 SVG 两个编辑器并存，快捷键隔离，导出 PNG / SVG。

  • 09 主题

    light / dark / macarons / tech-blue 四套内置主题对比，含选中、状态和缩放清晰度。

  • 10 横向泳道（白板风格）

    LR 方向的行泳道、竖排表头、标题、每条泳道自己的节点配色；拖节点换泳道，增删泳道。

  • 11 竖向泳道（经典风格）

    TB 方向的列泳道，无坐标数据全自动布局，文字自动换行，可切换主题和曲线连线。

  • 12 样式配置大全

    11 种形状、8 种箭头、3 种连线方式、连线与节点的样式覆盖，以及 createFlowTheme 自定义主题。

  • 13 泳道场景集

    请假、订单、CI/CD、工单、招聘、采购 6 个泳道场景，可切换方向、主题、紧凑泳道，对比避障路由开关。

  • 14 编辑配置项与 API

    逐项开关编辑能力、预设模式、缩放范围与网格、连线校验和删除确认、锁定节点，全部通过 setEditOptions 实时生效。

  • 15 Aurora 现代主题

    亮色与暗色两套现代主题：渐变强调条、悬停抬升、选中光环、极光背景、药丸标签，可模拟运行。

  • 16 导出与互通

    导出整图 PNG / SVG，与 Mermaid、draw.io 互相导入导出，保留泳道、形状、标签和箭头。
